# C08｜状态持久化与交接

## Purpose
将长期任务中有价值的状态保存为可检索、可更新、可交接的资产，减少上下文丢失和重复劳动。

## Procedure
1. 判断任务是否跨会话、模型、人员或平台。
2. 选择权威存储位置，避免多个互相冲突的主版本。
3. 记录目标、范围、状态、关键决策、证据、风险和下一步。
4. 对重要状态标记更新时间、来源和责任人。
5. 记录未验证假设和明确禁止事项。
6. 清理过时内容，保留必要变更历史。
7. 生成接手者可直接执行的交接说明。
8. 写入前检查权限和敏感信息。

## Output
Project State、Decision Log、Handoff Note 或更新后的知识资产。

## Acceptance
新接手模型无需原始长对话即可理解当前状态并安全继续；关键结论可追溯。
