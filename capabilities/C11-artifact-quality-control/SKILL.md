# C11｜交付物质量控制

## Purpose
按交付物类型检查内容、结构、视觉、格式、可用性和技术完整性。

## Procedure
1. 识别交付物类型、受众、场景和媒介。
2. 检查内容完整、事实准确、逻辑一致和语言质量。
3. 检查结构、层级、导航、图表和素材是否服务目标。
4. 检查格式、尺寸、可编辑性、兼容性和文件完整性。
5. 文档检查标题层级、目录、页码、表格、公式和引用。
6. 幻灯片检查叙事节奏、信息密度、字号、图文关系和投影可读性。
7. 代码检查构建、测试、错误处理、安全和维护性。
8. 输出问题分级和修订建议；修订后重新验收。

## Output
质量检查表、问题清单、修订结果和未解决项。

## Acceptance
交付物适合预定场景；关键质量问题已解决或明确披露。
