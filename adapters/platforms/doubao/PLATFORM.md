# 豆包 Adapter Profile

状态：DOCUMENTED（开放平台资料）｜当前账户实测：NOT_TESTED  
项目优先级：第三批

## 官方机制
豆包开放平台的官方开发文档提供 Skill 接入指南。指南将 Skill 定义为任务扩展单元，包含结构化指令、专业规则、工具依赖、参考资料和交付标准；连接器负责接入外部系统和业务动作，Skill 负责说明如何利用这些能力完成任务。

## 关键范围说明
当前核对的是豆包开放平台 Skill 接入资料，不自动代表普通消费者端豆包 App、豆包工作台或其他版本具有完全相同的 Skill 管理与导入能力。迁移前必须确认目标入口。

## PACS 映射
- Constitution / User Profile：作为全局规则或 Agent 基础说明。
- C01–C12：按开放平台 Skill 契约转换为单一任务能力。
- W01–W05：由 Agent 组合 Skills 与工具完成；如平台提供工作流定义，再映射为平台流程。
- Connectors：独立配置外部数据和动作权限。
- C07/C10：保留来源、证据、假设和验收要求。

## 导入方式
1. 确认目标是开放平台 Agent 还是消费者端产品。
2. 按开放平台最新 Skill 接入指南核对字段和包结构。
3. 先导入 C01、C07、C10 等低副作用能力进行试验。
4. 再验证工具依赖、连接器权限和多步骤流程。
5. 记录版本、调用方式、实际输出和未支持字段。

## 已知限制

- 未确认开放平台 Skill 格式与本仓库 YAML 元数据完全兼容；需要 Adapter 转换和实测。
