## 四、实现要点（可审计）

### 4.1 Local-first Router

- 前置入口选在 agent/inbox/inserted：该事件在 dsh-agent-loop/src/inbox.ts:228 同步 emit，早于 agent.ts:295 的 model.current() 选路，因此在这一刻调用 agent.model.select() 能真正改变本步 provider。
- 决策是确定性规则：显式 policy: local-only 一律本地；local-first 下按 classifier.cloudKeywords（正则源串）命中判 cloud，否则 local。无随机、无模型参与。
- 粘性：Map<sessionId, {provider, model, rule}>；同 session 后续 turn 复用同一决策，避免 retry/replay 期间换 provider。
- 保险丝：llm/stream 监听器对「已判 local 的 session」检查 options.provider，不符则直接 yield finish(kind=error, code=LOCAL_ROUTE_LOCKED)，不调用 next()，因此不可能出网。
- 清理：ctx.effect 在插件卸载时清空粘性表。

### 4.2 Budget Guard

- 位置：llm/stream waterfall，next() 之前。返回自定义 AsyncIterable 即可完全替代下游，因此「拒绝」等于零出网。
- 账本：append-only JSONL，事件 reserve / settle / release；读时重放计算 spent、pending、committed = spent + pending。
- 原子性：ledgerFile + .lock 用 fs.openSync(path, wx) 抢锁，把「读账本 → 判额度 → 追加 reserve」整体串行化；mtime 超过 lockStaleMs 视为陈旧锁回收；超过 lockTimeoutMs 抛错（fail closed）。
- 额度：单次 perRequestYuan、每日 dailyYuan；金额 = 输入估算（字符数按 inputTokensPerChar，与 chars/4 取大）+ 预留输出（maxTokens 或默认 1024）按 prices[provider]（CNY / 百万 token）折算。
- 未知价格：prices 无该 provider 时直接拒绝（BUDGET_UNKNOWN_PRICE，文案 refusing to guess），不猜测。
- 结算：成功流按最后一个 usage chunk 计算实际费用，写 settle（金额封顶 perRequestYuan）；失败/中断默认保留未决预留（releaseOnError 可显式开启释放），符合「账单不确定时不擅自归零」。
- 成功判定用 FinishReason 语义：kind 为 error 或 aborted 才算失败；其余（stop / length / tool-calls …）为成功。

### 4.3 Mock Provider

- 鸭子类型 adapter（不 extends LlmAdapter），实现 providerInfo / providerRetryPolicy / listModels / resolveModel / prepareCall / stream。
- prepareCall(provider, model, signal) 必须是位置参数：dsh-llm 的调用点是 adapter.prepareCall(provider, model, signal)（dsh-llm/lib/index.js:2334、:2428）。
- 抛错必须带 own failure 快照且 failure.code === error.code，否则会被归一化成 UNKNOWN（dsh-llm/lib/index.js:450-458、:519-521）。
- providerRetryPolicy 返回已摊平的 resolved 形状（顶层 initialDelayMs / maxDelayMs / jitterRatio）；返回嵌套 backoff 会让 llm-retry 计算出 NaN 延迟，导致 session event llm/retry carries non-JSON-serializable data。

## 五、过程中发现并修复的问题

| # | 现象 | 根因 | 处理 |
| --- | --- | --- | --- |
| 1 | INVALID_MODEL_INFO | mock 的 prepareCall 写成对象参数，provider/model 实为 undefined | 改为位置参数 |
| 2 | 本地 timeout 不触发重试 | 裸 Error 的 code 被归一化为 UNKNOWN（DSH 只信自家错误码） | 抛错时附加 own failure 快照 |
| 3 | 重试时 llm/retry 事件被拒收 | mock 返回嵌套 backoff，localDelay 读到 undefined → delayMs = NaN → 快照校验拒绝 | mock 返回摊平的 resolved retryPolicy |
| 4 | 预留永不结算 | guard 用 kind === success 判成功，而 FinishReason 无此成员 | 改为 kind !== error && kind !== aborted |
| 5 | T9 的 denied 日志缺 purpose | 超限拒绝走的是 reserve 失败分支，该分支日志只写 sessionId | 补 purpose 字段 |
| 6 | run-all 误报 FAILED | result.json 的 check 字段是 ok，runner 读 pass | 改读 ok |
